# مركز داريا الطبي - نظام إدارة الدور
## Daraya Medical Center Queue Management System

نظام شامل لإدارة دور المرضى في مركز داريا الطبي.

## 🚀 التشغيل السريع

### للمستخدمين العاديين:
- **تطبيق سطح المكتب:** `start-clinic.bat` (انقر مزدوج)
- **إصدار الويب:** `start-web.bat` (انقر مزدوج)

### للمطورين:
```bash
# الخادم
npm run dev

# التطبيق (في terminal آخر)
cd frontend && npm run dev        # ويب
cd frontend && npm run tauri:dev  # سطح مكتب
```

##   الميزات
- 🖥️ شاشة عرض كبيرة مع إعلانات صوتية
- 🏥 إصدار تذاكر مع طباعة حرارية
- 👨‍⚕️ واجهة طبيب شاملة
- 📱 تحديثات فورية عبر Socket.io

## 📋 المتطلبات
- Node.js 16+
- Windows 10+ (للتطبيق السطحي)
- طابعة حرارية (اختياري)

- **لا تحديث؟** جرب F5 أو تحقق من الاتصال
- **خطأ طباعة؟** تحقق من اسم الطابعة في الإعدادات
