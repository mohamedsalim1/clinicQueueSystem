# مركز داريا الطبي - نظام إدارة الدور
## Daraya Medical Center Queue Management System

نظام شامل لإدارة دور المرضى في مركز داريا الطبي، يتضمن:
- إصدار تذاكر الدور مع بيانات المريض
- شاشة عرض كبيرة مع إعلانات صوتية
- طباعة حرارية للتذاكر
- واجهة طبيب لإدارة الدور
- لوحة إدارة شاملة

## الميزات الرئيسية

### 🖥️ شاشة العرض الرئيسية
- عرض حالة جميع العيادات في الوقت الفعلي
- إعلانات صوتية عربية عند كل نداء
- شريط أخبار متحرك
- وضع ملء الشاشة

### 🏥 واجهة الاستقبال
- إصدار تذاكر جديدة مع بيانات المريض
- طباعة تذاكر حرارية فورية
- معاينة الطباعة قبل الطباعة الفعلية
- عرض إحصائيات اليوم

### 👨‍⚕️ واجهة الطبيب
- عرض المريض الحالي
- أزرار التحكم: التالي، تخطي، إكمال
- عرض قائمة الانتظار
- اختصارات لوحة المفاتيح

### 🖨️ الطباعة الحرارية
- دعم طابعات 80mm حرارية
- معاينة بصرية للتذكرة
- طباعة صامتة بدون حوارات

## التشغيل كتطبيق سطح المكتب (Windows)

### المتطلبات
- Windows 10 أو أحدث
- Node.js 16+
- Rust (سيتم تثبيته تلقائياً مع Tauri)
- طابعة حرارية (اختياري)

### التثبيت والتشغيل

1. **تثبيت التبعيات:**
   ```bash
   npm install
   cd frontend
   npm install
   ```

2. **تشغيل التطبيق للتطوير:**
   ```bash
   # تشغيل الخادم والتطبيق معاً
   start-clinic.bat

   # أو تشغيل منفصل:
   # Terminal 1: npm run dev (للخادم)
   # Terminal 2: cd frontend && npm run tauri:dev
   ```

3. **بناء التطبيق للإنتاج:**
   ```bash
   cd frontend
   npm run tauri:build
   ```

   سيتم إنشاء ملف `.msi` أو `.exe` في `frontend/src-tauri/target/release/bundle/msi/`

### إعداد الطابعة

1. قم بتوصيل الطابعة الحرارية
2. في إعدادات النظام، اذهب إلى "الطابعات والماسحات"
3. حدد اسم الطابعة (مثل "Thermal_Printer")
4. في التطبيق، اذهب إلى الإعدادات وأدخل اسم الطابعة

### قاعدة البيانات

يستخدم النظام PostgreSQL مع Prisma ORM.

1. **إعداد قاعدة البيانات:**
   ```bash
   # تثبيت Prisma CLI
   npm install -g prisma

   # إعداد قاعدة البيانات
   npx prisma migrate dev
   npx prisma db seed
   ```

2. **متغيرات البيئة:**
   أنشئ ملف `.env` في المجلد الجذر:
   ```env
   DATABASE_URL="postgresql://username:password@localhost:5432/clinic_db"
   JWT_SECRET="your-secret-key"
   ```

## الهيكل التقني

- **الخلفية:** Node.js + Express + Socket.io + Prisma + PostgreSQL
- **الواجهة الأمامية:** React + Vite + Socket.io Client
- **التطبيق السطحي:** Tauri (Rust) لتحويل إلى desktop app
- **الطباعة:** ESC/POS commands للطابعات الحرارية
